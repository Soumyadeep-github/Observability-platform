# Version 1.0.0

First local POC release: Python FastAPI backend, React and TypeScript UI, SQLite demo evidence, asset schema inspection, incident workflows, and dataset/column lineage.

The lineage graph supports inline schema expansion, automatic upstream/downstream column highlighting, and continuous curved connectors. Marquez/OpenLineage integration is optional; default lineage is fixture-backed.

Includes a UI screenshot gallery in the project README, automated tests, CI, and reorganized design documentation. This release retains the documented POC limitations; live source collectors and production deployment are not included.
